Mental Health Signal

        
End-to-end MLOps project

        
    
          
  • Explored a 5,000-record student dataset and trained a Random Forest regressor that predicts a mental health score (0 to 10) from 12 daily-habit features: R² 0.878, MAE 0.35 on held-out data.
    • 
          
  • Built one Scikit-learn Pipeline (log transform and scaling for numbers, ordinal and one-hot encoding for categories) so training and serving use identical preprocessing.
    • 
          
  • Compared three models and noted the Random Forest overfits (train R² 0.98), which tuning reduced but did not improve on test data.
    • 
          
  • Served with FastAPI behind Nginx and packaged as Docker images with Docker Compose.
    • 
          
  • A Jenkins pipeline runs on every GitHub push and deploys to AWS EC2, then runs a smoke test against the live server.
    • 
          
  • Security scan findings were fixed, and containers run as non-root with Docker health checks.
    •
